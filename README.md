# freedmde — DMDE 免费版批量自动恢复工具（含图形界面）

> 仅用于恢复**自己拥有合法权利**的数据。与 DMDE 官方无关联；请自行购买 DMDE 授权以支持开发者。

针对 DMDE 免费版"每次恢复操作只能处理**活动面板**（当前打开的目录）中最多 **4000** 个文件"的限制，
本工具通过 GUI 自动化（pywinauto）模拟人工操作：**自动逐个目录恢复，并按原相对路径完整还原目录树**，
支持断点续传、训练模式（限量试跑）、图形界面。

已在真实损坏 U 盘镜像（125GB，exFAT，分区表损坏）上完成全流程验证。

## 快速开始（图形界面）

1. **以管理员身份运行 DMDE**：
   - 打开磁盘/镜像（`Disk Images / Logs` 可添加 .bin 镜像文件）；
   - 分区表损坏时点 **Full Scan**（勾选文件系统 + Raw 签名），扫描完成后在
     "Main Results" 里选文件数最多的卷（如 `ExFAT 0`）→ **Open Volume**；
   - 提示保存扫描日志时建议保存（下次可加载，免重新扫描）；
   - 停在文件面板（左侧树确认在 `$Root`）。
2. **以管理员身份运行图形界面**：`python dmde_auto_gui.py`
   （没提权也没关系，界面右上角有"以管理员身份重启"按钮）。
3. 界面上：选输出目录（**务必另一块物理磁盘**）→ 需要的话点 **“选择要恢复的文件夹...”**
   （自动读取 DMDE 当前面板里的文件夹列表，勾选哪些就只恢复哪些分支；
   需要选更深层目录里的文件夹时，先在 DMDE 中进入该目录再点“刷新”）→ 点 **▶ 开始恢复**。
4. 运行期间不要动鼠标键盘。可以随时 **■ 停止**（等当前批次写完后安全停止，断点已保存）。

命令行方式（等价）：见下文"命令行用法"。

## 工作原理

DMDE 免费版规则（官方 EULA）：每次恢复操作最多处理活动面板中的 4000 个文件，**次数不限**。
人工操作 = "进一个目录 → 标记文件 → 恢复 → 确认"，成千上万个目录时极其枯燥。脚本自动化：

1. 按 PID 精确连接指定 DMDE 实例（多开绝不误伤）；
2. 从 `$Root` 起深度优先遍历目录树（双击进入 / `..` 返回，自动等待虚拟视图构建完成）；
3. 每个目录只标记**文件**（分块 shift+点击区间标记，逐块校验补漏），子目录在输出目录按
   原相对路径直接创建（空目录也不例外）；
4. 点击 `Recover...` → 自动填目标路径 → 自动处理全部弹窗：
   - 免费版激活提示 → `Continue with Free Edition`
   - `Process only files in the active panel?` → **Yes**（随后重新弹出的 Recover 对话框会再点一次 Recover）
   - 重名文件 → `Skip all` + OK（不覆盖已恢复文件）
   - 恢复完成统计 → OK；I/O 错误 → Skip（不中断）
   - 无法识别的弹窗自动**截图留证**（`_dmde_popup_*.png`）；
5. 每完成一批保存断点（`_dmde_auto_state.json`），中断后重跑自动续传，
   且会按磁盘实际文件数自愈断点（漏恢复的目录自动重做）。

## 命令行用法

```bat
python dmde_auto_recover.py --out D:\recovered [--goto-root] [--fresh] [--list-only]
                            [--chunk 3900] [--max-batches 3] [--pid N] [--root 目录] [--debug]
```

| 参数 | 说明 |
|---|---|
| `--out 路径` | 输出目录（必填，**另一块物理磁盘**） |
| `--goto-root` | 开始前自动回到 `$Root`（续传时建议加；GUI 默认勾选） |
| `--fresh` | 忽略断点从头开始（已恢复过的文件会以"重名跳过"处理，不会覆盖） |
| `--list-only` | 只遍历统计不恢复 |
| `--chunk N` | 每批文件数上限，默认 3900（官方上限 4000） |
| `--max-batches N` | 训练模式：恢复 N 批后自动停止（断点保存，取消限制可继续） |
| `--only "a,b"` | 限定只恢复这些文件夹分支（逗号分隔；GUI 的"选择要恢复的文件夹"即此功能） |
| `--pid N` | 多开 DMDE 时指定进程 |
| `--root 目录` | 先进入当前面板中名为该名的目录再开始 |

## 重要说明

- **运行期间勿动鼠标键盘**；要中止可直接关 DMDE 或点停止/Ctrl+C，断点已保存。
- **不要恢复到源盘/镜像所在盘以外的同名盘**——输出目录务必选另一块物理磁盘。
- **文件类别**：恢复已删除文件前，在 DMDE 的 Recover 对话框里勾选 `deleted`
  （DMDE 会记住该设置）。默认只有 non-deleted。
- 扫描日志：全盘扫描后 DMDE 询问保存时建议保存（如 `E:\fullscan.log`），
  下次在设备列表 `Disk Images / Logs` 里加载即可免重新扫描。
- 如需 DMDE 启动时自动打开某个镜像，可在 `dmde/dmde.ini` 的 `[Setup]` 段加一行：
  `startupimage=<镜像路径>`（本仓库不分发 DMDE 本体，请从 dmde.com 下载）。
- 目录/文件识别依据 DMDE 列表的尺寸列（目录显示 `[directory]`）与属性列（D 标志），
  启动时用图标索引自校准；无法识别的行按"有扩展名=文件"兜底并记录日志。
- `$Raw`、`$NonameFiles` 等虚拟目录按普通子目录递归恢复。

## 提速说明（复杂目录）

引擎已内置：ctypes 直读列表（约 8000 行/秒，比常规快 5-10 倍，失败自动回退）、
左侧目录树一次点击直达、弹窗响应压缩、行数快查、按需清标记。
实测 125GB 镜像训练 3 批（含 5 层深嵌套）约 105 秒。

复杂目录 further 提速的手段：

1. **用"选择要恢复的文件夹"排除垃圾分支** —— `FOUND.000`、`System Volume Information`、
   `LOST.DIR`、`$Raw` 等往往占掉大量目录数，排除后工作量常能减半；
2. 大目录保持每批 3900（减少操作次数）；分散在多次运行（断点续传，可过夜）；
3. 结构性上限：免费版每目录一次恢复操作（约 3-5 秒/目录的固定交互开销），
   目录数上千时总时长以小时计。DMDE 授权版无此限制（整树一次恢复，分钟级）——
   数据价值高时这是最直接的提速方式。
